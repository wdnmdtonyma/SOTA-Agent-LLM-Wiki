> V1 provider resolution 是当前活跑的模型入口：`packages/opencode/src/provider/provider.ts` 把 models.dev catalog、config、env、auth storage、plugin hooks、内建 custom loader 和 AI SDK package loader 合成可调用的 `LanguageModelV3`。

## 能回答的问题

- V1 当前如何从 `models.dev`、`opencode.json`、环境变量、auth 文件和 plugin hook 合成 provider？
- `googleVertexEndpoint` 对 `global` / `eu`/`us` / 其它 region 分别解析成什么 host？
- Cloudflare AI Gateway 的三分路由与 `cloudflareGatewayNpm()` 如何改写 npm？
- Azure OAuth 的 `accountId` 如何变成 Azure resource？Azure 还做不做 deployment discovery？
- `headerTimeout` / `chunkTimeout` 的全局默认与 `false` 语义是什么？
- V1 `Provider.getModel()` / `getLanguage()` / `defaultModel()` 的查找与缓存规则是什么？

## 定位
