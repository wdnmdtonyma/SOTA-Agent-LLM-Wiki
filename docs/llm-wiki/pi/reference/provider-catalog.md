## Provider 集合口径

本 catalog 的 membership 只按 `builtinProviders()` 的 return array 计算；当前逐行核验为 39 个 provider 实例，其中 38 个有静态 `MODELS` bucket，Radius 是纯动态 provider [E: packages/ai/src/providers/all.ts:52] [E: packages/ai/src/providers/all.ts:89] [E: packages/ai/src/providers/all.ts:128]。`builtinImagesProviders()` 另行返回 image-generation provider，不计入本表 [E: packages/ai/src/providers/all.ts:142] [E: packages/ai/src/providers/all.ts:143]。
