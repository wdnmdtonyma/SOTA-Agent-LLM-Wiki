## Ground Truth

`components/index.ts` 是 extension-facing barrel: 它 re-export `ArminComponent`、message components、selector/dialog components、`FooterComponent`、keybinding hint helpers、`renderDiff` 和 `truncateToVisualLines` 等符号 [E: packages/coding-agent/src/modes/interactive/components/index.ts:2] [E: packages/coding-agent/src/modes/interactive/components/index.ts:38]。`packages/coding-agent/src/index.ts` 再把这些 UI components 从 package public API 导出, 供 custom tools/extensions 复用 [E: packages/coding-agent/src/index.ts:406] [E: packages/coding-agent/src/index.ts:444]。

`InteractiveMode` 直接 import 大多数 session-bound components, 包括 `ArminComponent`、message components、`CustomEditor`、selector/dialog components、`FooterComponent`、`ThinkingSelectorComponent`、`createMermaidMarkdownTransformer` 和 `ToolExecutionComponent` [E: packages/coding-agent/src/modes/interactive/interactive-mode.ts:132] [E: packages/coding-agent/src/modes/interactive/interactive-mode.ts:169] [E: packages/coding-agent/src/modes/interactive/interactive-mode.ts:148]。startup UI 复用 `ExtensionSelectorComponent`、`FirstTimeSetupComponent` 和 `ExtensionInputComponent`, 在进入长期 interactive session 前临时创建 TUI [E: packages/coding-agent/src/cli/startup-ui.ts:150] [E: packages/coding-agent/src/cli/startup-ui.ts:251]。`pi config` 命令直接 import `ConfigSelectorComponent`, 但该 component 不经过 `components/index.ts` barrel [E: packages/coding-agent/src/cli/config-selector.ts:7] [E: packages/coding-agent/src/cli/config-selector.ts:33] [U]。

本 catalog 的实例粒度按目录文件展开: 本轮重数是 **45** 个 `.ts` 文件全部出现, 其中 `index.ts` 是 barrel 文件而不是 runtime component class [I]。`pi-logo.ts` 与 `themed-text.ts` 不在 `components/index.ts` barrel 中, 由 `interactive-mode.ts` 直接 import [E: packages/coding-agent/src/modes/interactive/interactive-mode.ts:155] [E: packages/coding-agent/src/modes/interactive/interactive-mode.ts:168]。如果未来把 catalog instance_count 改成“public exported component/helper 数”, `index.ts` 是否算作实例需要重新定义 [U]。
