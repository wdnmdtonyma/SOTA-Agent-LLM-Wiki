## Ground Truth

本 catalog 的实例粒度按目录文件展开: `packages/coding-agent/src/modes/interactive/components/` 现有 **48** 个 `.ts` 文件,全部出现在下方表格。`index.ts` 是 barrel 文件而不是 runtime component class [I]。`daxnuts.ts` 已从该目录删除,本节点不再列 `DaxnutsComponent`。
