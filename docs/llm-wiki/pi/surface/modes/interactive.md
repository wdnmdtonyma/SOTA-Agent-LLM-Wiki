> `surface.modes.interactive` 描述 pi-coding-agent 的 terminal interactive mode: `InteractiveMode` 持有当前 `AgentSessionRuntime`, 启动 `pi-tui` UI, 接收用户输入, 把普通 prompt 送入 `AgentSession.prompt()`, 并把 agent events 渲染回 chat/status/tool UI。

## 能回答的问题

- `InteractiveMode` 是什么时候创建 TUI、editor、footer 和长期 containers 的?
- 默认 TUI 是 fullscreen 还是 regular? `tuiMode` / `--tui-mode` 怎样覆盖?
- `quietStartup: "header"` 与 `true` 分别藏掉哪些 startup 输出?
- Apple Terminal 为什么不画半块 logo,画什么代替?
- `InteractiveMode.run()` 对 startup warnings、invalid settings diagnostics、initial messages 和普通交互 loop 做了什么?

- `/model` 与 `/thinking` 默认是改 session 还是写 global default? persist 走哪条 save keybinding?
- `/share` 如何先 Radius 再 gh gist, 以及 `pi.share` custom entry 带什么?

[subsys.coding-agent.interactive-orchestration](../../subsystems/coding-agent/interactive-orchestration.md) 覆盖同一 `InteractiveMode` 文件里的 deeper orchestration, 包括 containers、extension UI、event rendering、reload 和 compaction queue;本节点保留 T1 粒度, 不逐个展开每个 selector/component 的内部 rendering contract [I]。
